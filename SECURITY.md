# Security

## What this repo contains

- **No real employee data.** All data is generated by Faker with a fixed seed.
- **No proprietary prompts** from any employer.
- **No internal system schemas** — the Workday, Greenhouse, and Docebo shapes are reconstructed from publicly documented APIs.
- **No secrets.** `.env` is gitignored; only `.env.example` is committed.

## Secret hygiene

- `pre-commit` runs `gitleaks` and `detect-secrets` on every commit.
- GitHub Actions are scoped to `contents: read` and never receive secrets on PR builds from forks.
- Terraform uses variables only; no hardcoded project IDs.

## Reporting vulnerabilities

Open a private GitHub security advisory. Do not file public issues for security reports.
